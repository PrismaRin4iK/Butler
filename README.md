# 🎩 Butler — Smart Backlog

> **Персональный AI-дворецкий для ликвидации «кладбищ закладок» и преодоления паралича выбора.**  
> Сервис агрегирует ссылки на YouTube-видео, статьи для чтения и пользовательские задачи в единый бэклог, но вместо бесконечных демотивирующих списков предлагает **строго одну** активность за раз — под ваше доступное время и текущий уровень энергии.

---

## 🌟 Философия проекта

В современном вебе легко утонуть в сохранённых материалах: сотни вкладок в браузере, тысячи видео в «Смотреть позже» на YouTube, бесконечные статьи в закладках. 

**Butler** решает эту проблему радикально:
1. **Никаких бесконечных лент.** Вы не листаете каталог, теряя остатки сил на выбор.
2. **Принцип персонального дворецкого.** Вы сообщаете два параметра:
   - ⏱ **Сколько у вас времени** (10, 20, 30, 45, 60+ минут).
   - ⚡️ **Сколько у вас сил** («Устал», «В норме», «Заряжен»).
3. **Защита от истощения.** Дворецкий уважает ваше состояние: если вы устали после тяжелого дня, он ни при каких условиях не предложит вам таскать бетонные блоки или разбираться в квантовой физике.

## ✨ Ключевые возможности

### 1. Универсальный умный инжест (Universal Ingestion)
- **YouTube:**
  - Одиночные ролики, Shorts, трансляции и видео из плейлистов (`/watch`, `/shorts/`, `youtu.be/`, `/live/`).
  - Автоматическое определение длительности (ISO 8601 $\to$ минуты), названия, канала и превью.
  - Поддержка пакетного импорта пользовательских плейлистов или быстрое сохранение ссылки на плейлист.
- **Статьи (Articles):**
  - Извлечение чистого контента страницы через `@extractus/article-extractor` и Cheerio.
  - Автоматический расчет времени чтения: $\max(2, \lceil\text{wordCount} / 200\rceil)$ минут.
  - Сохранение HTML для чтения в офлайн/ридер-режиме.
- **Пользовательские задачи (Custom Tasks):**
  - Быстрый ввод названия и заметок.
  - Выбор времени (5, 15, 30, 60 мин) или автоматическая оценка через ИИ.
  - Возможность вручную указать сложность («Легко», «В норме», «Трудно») или доверить оценку ИИ.

### 2. Человекоцентричное AI-обогащение (Groq AI)
Каждый добавленный элемент анализируется через сверхбыструю языковую модель Groq (`openai/gpt-oss-120b` / `qwen/qwen3.8-27b`):
- **Суммарный уровень энергии (`energy_level`):** объективная оценка требуемых сил (физический труд, умственная концентрация, волевые усилия).
- **Микро-хук (`ai_summary`):** ровно одно мотивирующее предложение на русском языке без спойлеров, объясняющее, почему стоит открыть/сделать это прямо сейчас.
- **Теги (`tags`):** до 3 релевантных категорий для фильтрации и контекста.

### 3. Алгоритм Дворецкого (The Butler Engine)
- **Жёсткий фильтр безопасности:** если пользователь указал **«Устал» (`low`)**, любые задачи и материалы категории **`high` полностью исключаются**.
- **Приоритет легкого отдыха:** при состоянии «Устал» алгоритм подбирает исключительно лёгкий расслабляющий контент.
- **Фокус на пике сил:** при состоянии «Заряжен» сложные задачи получают максимальный скоринг (+70 очков), стимулируя разобрать то, что долго откладывалось.
- **Штраф за навязчивость:** -30 очков, если активность уже предлагалась менее 24 часов назад.
- **Бонус за выдержку (Aging Bonus):** +1 очко за каждые 3 дня нахождения в бэклоге (максимум +20 очков), чтобы старые важные задачи не терялись.

### 4. Режим фокусировки (Focus Card)
- Полноэкранная карточка активности.
- **Встроенный YouTube-плеер** без отвлекающих рекомендаций видеохостинга.
- **Встроенный Reader Mode** для чтения статей в комфортной типографике без рекламы и баннеров.
- **Интерактивный таймер обратного отсчёта** с паузой и сбросом.
- Быстрые действия:
  - ✅ **Выполнить** — перемещение в архив выполненных.
  - 🔄 **Другое** — временно отложить и запросить следующую рекомендацию.
  - 🗑 **Выбросить** — переместить в dismissed.

### 5. Архив и управление бэклогом (Storage & Archive)
- Модальное окно полного хранилища с мгновенным поиском по названию, автору и тегам.
- Вкладки статусов: «Входящие», «Выполненные», «Выброшенные».
- Фильтрация по типам: Все, Видео, Статьи, Задачи.
- Восстановление элементов обратно в работу или безвозвратное удаление.

## 🚀 Быстрый старт и локальный запуск

### 1. Предварительные требования
- Установленный **Node.js** версии 20+ (проверено на Node.js 22/24).
- Менеджер пакетов `npm`.
- Проект в [Supabase](https://supabase.com/) (бесплатного тарифа достаточно).
- Бесплатный API-ключ [Groq](https://console.groq.com/keys).

### 2. Клонирование репозитория
```bash
git clone https://github.com/PrismaRin4iK/Butler.git
cd Butler
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env.local` в корне проекта:
```bash
cp .env.example .env.local  # или создайте вручную
```

Заполните ключи в `.env.local`:
```env
# 1. Supabase (Dashboard -> Project Settings -> API)
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key

# 2. Groq AI (https://console.groq.com/keys)
GROQ_API_KEY=gsk_your_groq_api_key

# 3. YouTube Data API v3 (Опционально)
# Если ключ не указан, работает встроенный oEmbed и HTML-парсер
YOUTUBE_API_KEY=your-youtube-api-key
```

### 4. Накатывание миграции базы данных
В Supabase Dashboard перейдите в **SQL Editor** и выполните содержимое файла:
[`supabase/migrations/20250910000000_initial_schema.sql`](supabase/migrations/20250910000000_initial_schema.sql)

Миграция создаст:
- Таблицу `profiles` (с каскадной связью с `auth.users`).
- Таблицу `backlog_items` с индексами и проверками статусов.
- Триггер `handle_new_user()` для автоматического создания профиля.
- Политики Row Level Security (RLS) для защиты данных пользователей.

### 5. Запуск сервера разработки
```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в вашем браузере.
